# Multi-Page Blog Website

A three-page blog built with HTML5 and CSS3 (Flexbox and Grid). One shared stylesheet, identical header and footer on every page, and an active-page indicator in the navigation.

https://tsg-webdev-p03-roshaanwaheed.vercel.app/

## Pages
| Page | File | Contents |
|---|---|---|
| Home | `index.html` | Hero, topics, link to the blog |
| Blog | `blog.html` | Four post cards with image, title, date and preview |
| Contact | `contact.html` | Contact details and a styled form |

## Folder structure
```
index.html
blog.html
contact.html
css/style.css
images/post-1.svg ... post-4.svg
README.md
```
